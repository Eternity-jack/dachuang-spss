分析环节 SPSSPRO 菜单路径 放什么变量？
1. 信度分析 问卷研究 → 信度分析 (Cronbach's α) 同维度的 3~5 道量表打分题（定量）
2. 效度分析 问卷研究 → 效度分析 (探索性因子) 全部量表打分题（如 16 题）
3. 描述统计 通用方法 → 频数分析 / 描述性统计 性别/年级等选频数；打分/价格选描述
4. 差异分析 通用方法 → 独立样本 t / 单因素方差 / 卡方 X=分组(年级/性别)，Y=打分或分类
5. 相关性 通用方法 → 相关性分析 各维度平均分（定量）
6. 多元回归 通用方法 → 线性回归 (OLS) Y=购买意愿，X=痛点/有用性/易用性等
